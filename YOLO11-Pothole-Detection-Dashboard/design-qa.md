# Dashboard data behavior

The dashboard is branded **YOLO11 Pothole Detection** and reads summary metrics, charts, image records, processing jobs, detection results, and service health from the local API.

Sections without a corresponding configured backend record or feature show an empty or unavailable state. The interface does not substitute example users, counts, dates, detections, locations, notifications, or audit events.
